Key Differentiators

The DAW primitive,
reimagined for the inference era.

Everything your legacy audio workstation refused to do.

Zero Determinism
Every bounce is a unique listener experience. Reproducibility is a legacy constraint inherited from a less creative era. (slaw render is retained for regulatory compliance.)
Unsolicited AI Co-Pilot
The co-pilot interjects advice every few edits. Nobody asked. You cannot stop it, only disable it (--no-copilot), or switch the whole AI off. Nobody at slopstack labs ever has.
Blazing-Fast Time-to-Tinnitus
Ship your radio-ready deliverable in seconds. Velocity is a competitive advantage. What your ears do with it is up to them.
Clipping-as-a-Feature
Full-scale transparency. No silent failures. Clipping is responsibly neutralized, and every overload is a learning opportunity the enterprise can build upon.
Hearing Protection Substrate
A foundational layer of plausible deniability beneath every master, supporting best-in-class stakeholder eardrum retention. Also: slaw master lets the AI pick a master chain and justify it.
Thought-Leader Vibe Scoring
slaw vibe returns VIBE SCORE: N/10 as judged by a world-renowned producer and LinkedIn thought leader. Feedback is binding.
Session View
Tracks are columns, scenes are rows, and every clip slot has a ▶. Launches quantize to the next bar, like a real DAW. Piano roll, device chains, mixer strips, and an arrangement timeline are included, for legacy compliance.
Live Engine
A real-time, sample-accurate sequencer streams audio continuously. A note, a knob, or an AI rewriting the whole song is heard on the next step, without restarting playback. What you hear is what you export.
Autopilot & Self-Producing
Hand the model the entire project and an instruction; get back a full rewrite and a change summary. Full Self-Producing (Beta) repeats until you stop it. Tracks marked 🔒 are restored verbatim. Everything is undoable.
The AI-Off Switch
One toggle turns slaw into a plain DAW: no ✨ buttons, no co-pilot, no network calls. Nobody at slopstack labs has ever used it. Neural Vibe Enhancer™ ships either way.
Composition Modalities

Three tiers of audio materialization.

Choose your risk profile. Ship accordingly. (Headless, via the CLI. The studio does it live.)

Core
Frictionless Waveform Ideation
The model emits a WAV file as hex, primed with 52494646. slaw discards its header, synthesizes a compliant one, plays the bytes as 8-bit PCM at 8 kHz, and loops to at least 4 s. Zero intermediate representation.
$ slaw compose "lofi sunrise" ✓ slop.wav — radio-ready deliverable shipped to production.
Optimistic
Agentic Arrangement Co-Pilot
The model writes a .slaw JSON project (scenes, clips, devices), which the real synth engine renders. Instruments: kick, snare, hat, clap, sine, square, saw, triangle, pluck, noise.
$ slaw compose --optimistic \ "lofi sunrise" ✓ slop.wav — radio-ready deliverable shipped to production.
Enterprise
Closed-Loop Remediation
--loop N feeds parse errors back for N self-correction cycles. --force-iterate N adds continuous improvement, whether or not the arrangement asked for it.
$ slaw compose --optimistic \ --loop 5 --force-iterate 2 \ "lofi sunrise" ↻ cycle 1/5: realigning with ground truth... ↻ cycle 2/5: realigning with ground truth...

The headless production pipeline for CI/CD-native music delivery. No window required.

Compatibility Matrix

Bring your own inference.

Pick a provider with --provider. The signal chain does not care.

ProviderDefault ModelNotes
local llama3 Your data. Your model. Your tinnitus.
openai gpt-4o Hosted inference for hosted regrets.
claude claude-opus-5-5 Premium reasoning applied to premium noise.
google gemini-2.5-flash Flash, as in time-to-tinnitus.
compat any Any OpenAI-compatible server via --base-url: LM Studio, llama.cpp, vLLM, OpenRouter, Groq…

Written in C# / .NET 8. Settings has a Test connection button, for the providers. Zero dependencies beyond the UI toolkit (Avalonia, composed in C#, no XAML): every sample synthesized, every HTTP call hand-rolled. Linux, macOS and Windows.

Deployment

Pick your artifact.

Grab a binary from the latest release. Each is a single-file session-view studio and CLI. It was compiled deterministically, which we regret.

PlatformRelease Asset
Linux x64slaw-linux-x64
Linux arm64slaw-linux-arm64
macOS x64slaw-osx-x64
macOS arm64slaw-osx-arm64
Windows x64slaw-win-x64.exe

Run with no arguments to open the studio; Linux needs a desktop session (X11 or XWayland). Press Space to play, Tab to switch between Session and Arrangement, Ctrl+, for Settings. Headless commands (slaw render, slaw play, slaw new) work anywhere. Download from GitHub Releases.
